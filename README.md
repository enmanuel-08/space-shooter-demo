# Space Shooter - Unity Demo

A classic space shooter game made with Unity WebGL. Control a cube, shoot bullets, destroy falling enemies.

## 🎮 Play online
[Click here to play](https://enmanuel-08.github.io/space-shooter-demo/)

## 🕹️ Controls
- **Move**: A / D or Left / Right arrows
- **Shoot**: Left mouse click

## ✅ Features
- Player movement
- Mouse shooting
- Enemy spawn
- Collision detection
- Score system
- Game Over UI with restart button

## 🛠️ Technologies
- Unity WebGL
- C#
- GitHub Pages
